# Third-party data notices

Ordvi's optional offline language packs are built from open lexical data.

## PanLex / ACoLi Dicts

The translation pairs are derived from the PanLex database via the TIAD-TSV
exports published by the ACoLi Dictionary Graph.

- PanLex: https://panlex.org
- ACoLi Dicts: https://github.com/acoli-repo/acoli-dicts
- Data license: CC0 1.0 Universal

PanLex asks for attribution although attribution is not a condition of CC0.

## FrequencyWords

Frequency rankings are used only to prioritize which PanLex translation pairs
are included in the compact Ordvi packs.

- Project: https://github.com/hermitdave/FrequencyWords
- Content license: CC BY-SA 4.0
- Source corpus: OpenSubtitles-derived frequency data

Ordvi keeps the attribution and license notice with the generated pack metadata.
